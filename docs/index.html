1 iPhone: get round text with screenshots + Live Text

Music League’s in-app browser usually won’t let you copy the page. Screenshot the round, then OCR the text:

  1. Scroll through the round in Music League and screenshot every screen until all songs are captured.
  2. Open Photos → a screenshot → tap Live Text (text icon in the corner).
  3. Select All → Copy.
  4. Come back here and paste into step 2. Multiple shots? Paste each block in order.
  5. Turn on Live Text mode below if you see 4/1000-style footers but no Album art lines.

On a computer with a saved round .html file, paste that instead — more accurate.
