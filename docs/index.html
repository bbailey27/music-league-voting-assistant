Getting round text on iPhone

Music League often opens in an in-app browser where you cannot copy page text. Use screenshots + Live Text instead:

  1. In the Music League app, scroll through the round and screenshot each screen until every song is captured.
  2. Open Photos → open a screenshot → tap the Live Text button (text viewfinder icon).
  3. Select All on the recognized text → Copy.
  4. Paste below. If you used multiple shots, paste each block in order (or stitch in a photos app first — the parser ignores “Screenshots Stitched” trailers).
  5. Enable Lenient (Live Text) if the paste lacks Album art blocks but still has N / 1000 footers on comments.

On desktop, prefer saving the full round .html export — paste that here for best accuracy.
